The first release.

- Four founders, each in dark and light: Godric, Salazar, Rowena and Helga.

- Clearly separated code colors for every major language, plus semantic highlighting.
- Full coverage of the workbench: terminal, Git and diffs, IntelliSense, hovers, peek views, the debugger, testing, the minimap and bracket pairs.
- Every code color passes WCAG AA contrast, checked on every build.
